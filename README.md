# Pakko Telegram Bot

Pakko - Telegram-бот для поиска и анализа информации в стиле Perplexity. Бот работает в личных сообщениях и группах, использует OpenAI Responses API, умеет подключать hosted web search, хранит краткий контекст чата в SQLite и автоматически сжимает историю.

## Возможности

- ответы на русском и английском языках;
- работа в личных чатах, группах и супергруппах;
- в группах бот отвечает только на `@username`, `Pakko` или `Пакко`;
- команды `/start`, `/help`, `/clear`, `/status` с практичными подсказками и человекочитаемым статусом памяти;
- контекст отдельно для каждого чата;
- очистка контекста через `/clear`, явную просьбу или молча после 10 минут неактивности;
- суммаризация длинной истории для снижения расхода токенов;
- опциональный веб-поиск через OpenAI hosted `web_search` с коротким статусом проверки источников;
- структурированные ответы с фактами, предположениями, выводами и источниками;
- логирование времени ответа, использования поиска, токенов и примерной стоимости;
- понятный ответ на вложения и нетекстовые сообщения: бот просит продублировать вопрос текстом.

## Архитектура

```text
pakko/
  config.py           # Pydantic settings из .env
  logging.py          # стандартное логирование
  main.py             # точка входа
  assistant/          # бизнес-оркестрация ответа
  llm/                # OpenAI Responses API
  memory/             # SQLite-репозиторий и контекст чата
  search/             # эвристика необходимости веб-поиска
  summarization/      # сжатие истории
  telegram/           # aiogram handlers и групповые триггеры
```

## Локальный запуск

1. Установите Python 3.12+.
2. Создайте и активируйте виртуальное окружение.
3. Установите проект:

```bash
pip install -e ".[dev]"
```

4. Создайте `.env` из примера:

```bash
cp .env.example .env
```

5. Заполните `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` и `OPENAI_API_KEY`.
6. Запустите бота:

```bash
python -m pakko.main
```

## Docker

```bash
cp .env.example .env
docker compose up --build
```

SQLite-файл хранится в `./data`.

## Конфигурация

Основные переменные:

- `OPENAI_MODEL` - модель без изменения кода. По умолчанию `gpt-5.4-mini`, так как в документации OpenAI она описана как более дешевый и быстрый mini-вариант для рабочих задач.
- `OPENAI_REASONING_EFFORT` - `none`, `low`, `medium`, `high` или `xhigh`.
- `MAX_ANSWER_SECONDS` - мягкий бюджет на дополнительные попытки повысить уверенность ответа, например повтор с веб-поиском. Первичный ответ не обрывается по этому таймеру. По умолчанию `30` секунд.
- `ENABLE_WEB_SEARCH` - включает hosted web search.
- `WEB_SEARCH_CONTEXT_SIZE` - размер поискового контекста: `low`, `medium`, `high`.
- `CONTEXT_TTL_SECONDS` - время неактивности, после которого контекст чата очищается.
- `SUMMARIZE_AFTER_MESSAGES` - порог сообщений для суммаризации.
- `MAX_RECENT_MESSAGES` - сколько последних сообщений оставлять после суммаризации.
- `OPENAI_INPUT_PRICE_USD_PER_MILLION` и `OPENAI_OUTPUT_PRICE_USD_PER_MILLION` - цены для примерного логирования стоимости. Проверяйте их перед production-запуском.

## Поведение в группах

Бот игнорирует обычные сообщения в группах. Он отвечает только если текст содержит:

- `@pakkkobot` или другой username из `TELEGRAM_BOT_USERNAME`;
- `Pakko`;
- `Пакко`.

Сравнение регистронезависимое. Адресация удаляется перед отправкой запроса в LLM.

## Веб-поиск

Pakko сначала применяет легкую эвристику: поиск сразу включается для запросов про новости, актуальные данные, текущие должности и статусы, официальные сведения, статистику, цены, источники, фактчекинг, релизы, даты выхода и явные просьбы "найди" / "поищи" / "latest" / "verify". Каждый сырой ответ LLM содержит технический маркер уверенности, который удаляется перед отправкой пользователю. Если маркер показывает низкую уверенность или необходимость веб-проверки, бот повторяет запрос с OpenAI `web_search`, пока остается бюджет улучшения `MAX_ANSWER_SECONDS`. Низкая уверенность должна оставаться в финальном ответе только если поиск уже использовался или не успел усилить ответ.
